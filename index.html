GUIA: PUBLICAR NO GITHUB PAGES

Passo 1: Salve o arquivo principal

Salve todo o código desta aplicação em um único arquivo com o nome exato: index.html

Passo 2: Crie o Repositório no GitHub

  1. Acesse o github.com/new.
  2. Dê um nome ao repositório (ex: midnight-chat-lofi).
  3. Marque como Public.
  4. Clique em Create repository.

Passo 3: Faça Upload do Arquivo

Na página do repositório, clique em "uploading an existing file", envie seu arquivo index.html e clique em Commit changes.

Passo 4: Ativar o GitHub Pages

  1. Abra a aba Settings do seu repositório.
  2. No menu esquerdo, selecione Pages.
  3. Em Branch, selecione main e a pasta /(root). Clique em Save.

🎉 Pronto!
